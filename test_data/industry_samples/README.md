# Industry Sample Packs

Each folder is a complete two-period analysis scenario. Upload the `transactions.csv`
and `business_context.txt` from one folder together on the first screen. The CSV feeds
the deterministic finance pipeline; the context note is retained as RAG evidence.

| Industry | Main variance story |
| --- | --- |
| `b2b_saas` | Enterprise expansion increased revenue while cloud spend rose. |
| `ecommerce` | Back-to-school demand lifted sales and paid media costs. |
| `healthcare_clinic` | New contracts increased patient services and clinical labor. |
| `logistics` | A major shipper expanded lanes, raising fuel and carrier costs. |
| `hospitality` | Conference bookings improved room revenue and housekeeping spend. |
